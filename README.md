# Regulatory Change Radar

> Live demo: _(link added after first deploy)_

Compliance teams at banks, insurers, and security orgs drown in regulator
publications across the US and Canada. Missing one update — an OSFI B-13
revision, a NYDFS Part 500 amendment — means audit findings. This radar
automates horizon scanning: continuous watch → plain-English change summaries
→ mapping onto your control library → a prioritized action list.

Runs on free-tier/local models. The demo runs entirely on seeded data with
zero API keys.
